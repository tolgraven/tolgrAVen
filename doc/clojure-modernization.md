# Clojure modernization for tolgrAVen.se

The website builds its Ring server with Leiningen and JDK 21, and its browser and Node renderers with Shadow CLJS. A change to shared code can affect all three. The following decisions use the versions published on 22 November 2026. The manifests and lockfile remain the source for the installed versions. [Dependency ownership and upgrade commands](dependencies.md) · [Test environments](testing.md)

## Language and runtime

| Where | What to use | Why here |
| --- | --- | --- |
| JVM runtime and dependency tooling | Clojure **1.12.7** | Both Lein pins previously used 1.12.6. The patch disables Java binary serialization and deserialization of Clojure functions by default. Ordinary Transit and JSON data remain usable. [Official downloads](https://clojure.org/releases/downloads) · [Patch notes](https://github.com/clojure/clojure/blob/clojure-1.12.7/changes.md) |
| Typed Java boundaries | Clojure 1.12 method values, constructors, array class symbols and functional interfaces | An unambiguous method such as `String/.length` can go directly into `map`. Give overloaded methods parameter tags where needed. At a resolved Java call accepting a single-abstract-method interface, a matching Clojure function can replace a one-method `reify`. The class and method still belong in the namespace that owns the integration. [Java interop reference](https://clojure.org/reference/java_interop) |
| Java streams | `stream-into!`, `stream-reduce!`, `stream-transduce!` or `stream-seq!` | Consume a Java stream where it is acquired. For a file-backed stream such as `Files/list`, use `with-open` and realize the result before returning. Normal Clojure collections need none of this machinery. [Clojure 1.12 release](https://clojure.org/news/2024/09/05/clojure-1-12-0) |
| JVM collections and tasks | `partitionv`, `partitionv-all`, `splitv-at` where vectors are the intended result. JDK 21 virtual threads where callers block. | The 1.12 changes to delays and lazy sequences also reduce virtual-thread pinning. Keep application limits on in-flight GitHub, preview and SSR work. Changing the thread implementation leaves upstream quotas and memory limits in place. [Clojure 1.12 release](https://clojure.org/news/2024/09/05/clojure-1-12-0) |
| JVM parsing and simple transforms | `parse-long`, `update-vals`, `update-keys`, `clojure.string`, `clojure.math` | Some of the clearest replacements already shipped in 1.11 or earlier. In the GitHub calendar parser, `parse-long` returns nil for invalid or out-of-range input. The parser still rejects malformed upstream counts explicitly. [Clojure API](https://clojure.github.io/clojure/clojure.core-api.html#clojure.core/parse-long) |
| Candidate JVM language changes | Trial **1.13.0-alpha11** on an isolated profile | Checked map destructuring (`:keys!`), `req!`, and the `:missing` and `:excess` directives could distinguish absent provider fields from fields explicitly set to nil. The syntax has changed across alphas. Keep Malli at external boundaries and exercise both compilers before adopting a JVM language feature in a `.cljc` file. [Development release](https://clojure.org/releases/downloads#dev) · [Checked keys](https://clojure.org/news/2026/07/02/clojure-1-13-alpha1) · [Nested maps](https://clojure.org/news/2026/09/15/clojure-1-13-alpha7) · [Alpha 11 fix](https://clojure.org/news/2026/10/27/clojure-1-13-alpha11) |

Clojure 1.13 alphas now require Java 17 and emit Java 17 bytecode. The production JDK 21 meets that baseline. Recheck compiler tooling, optional profiles and the packaged server when trialling 1.13. [Java baseline change](https://clojure.org/news/2026/07/21/clojure-1-13-alpha5)

The alpha also adds `merge-deep` and `merge-deep-with`. The Supabase store recursively merges document maps and replaces sequence values. The browser utility can concatenate seqs. Verify both contracts separately before consolidating them. Loading the current website graph on alpha11 produced name-shadowing warnings for those functions in `taoensso.encore`. The GitHub calendar and cache tests passed on that graph. [Alpha 8 additions](https://clojure.org/news/2026/09/30/clojure-1-13-alpha8) · [Document merge](../src/cljc/website/supabase/store.cljc) · [Browser merge](../src/frontend/website/util.cljs)

Project dependencies still go in Lein profiles and the lockfile. Clojure 1.12's REPL library-loading functions rely on tools.deps basis information. They do not update a Lein prefab or a deployed artifact. [REPL library management](https://clojure.org/reference/repl_and_main#_adding_libraries_at_the_repl)

## Browser I/O, effects and tests

The compiler pinned here, **ClojureScript 1.12.145**, supports `^:async` on a function and `await` inside its body. Calling that function returns a JavaScript Promise. An awaited rejection follows normal `try`/`catch` control flow. A separately defined inner callback has its own async context. The compiler also supports `(deftest ^:async ...)`. The callback-taking `cljs.test/async` and channel operations in `core.async/go` have different completion contracts. [Pinned compiler changes](https://github.com/clojure/clojurescript/blob/r1.12.145/changes.md) · [Compiler and test examples](https://github.com/clojure/clojurescript/blob/r1.12.145/src/test/cljs/cljs/async_await_test.cljs)

Use `await` when each step requires the previous result. If two reads can run together, start both and combine them with `website.async/all`. Use `all-settled` if both outcomes must be reported. A callback-driven API such as IndexedDB can expose a single Promise from its adapter. Cancellation needs its own owner and cleanup, including when a consumer unmounts while waiting. Existing channel-based lifecycle tests can migrate one fixture at a time by checking that rejection still fails the test and teardown still runs. [Browser adapters](../src/frontend/website/async.cljs) · [Lifecycle tests](../test/cljs/website)

New browser requests use `website.http/request!`. Components and managed data sources can call the transport directly. Declarative re-frame handlers return the `:http/fetch` effect. The common transport owns query and header encoding, JSON and Transit, same-origin CSRF handling, aborts, timeouts, and HTTP error normalization. Fetch fulfills on HTTP error statuses, so the transport checks the status. Uploads requesting byte progress use the browser's `XMLHttpRequest.upload` events. Callers specify whether they need progress. [Site transport](../src/frontend/website/http.cljs) · [Fetch status handling](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch#checking_response_status) · [Upload progress](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest/upload)

Two packaged alternatives address different portions of that contract. `lambdaisland/fetch` returns a Promise of a Ring-shaped response and includes Transit/JSON codecs. It could replace the generic Fetch portion if the site tests also pass for custom handlers, error bodies and cancellation. `superstructor/re-frame-fetch-fx` registers a re-frame effect. The site's source loaders and SSR modules also call transport code outside event dispatch, so they still need a callable adapter. Switching every consumer to a channel or layering two HTTP effect registries would add a second lifecycle for the same request. [lambdaisland/fetch](https://github.com/lambdaisland/fetch) · [re-frame-fetch-fx](https://clojars.org/superstructor/re-frame-fetch-fx)

## Keeping handlers readable

- Make a short handler tell the story in application terms. In `website.modules.github.activity`, each public reader parses the calendar or activity day through named steps. The fetcher passes the Jsoup document it already has. There is no need to serialize the tree to HTML and parse it again. The same parsers can be exercised with captured HTML. [GitHub activity parser](../src/backend/website/modules/github/activity.clj) · [Parser fixtures](../test/clj/website/github_activity_test.clj)
- In the Strava graph, a small Canvas adapter draws the selected sample with five arc arguments and a full turn expressed as `(* 2 math/PI)`. Checking the actual argument vector catches a bug that a screenshot could miss. Keep the small standalone entrance script’s native DOM/Math operations local to its bundle. [Graph drawing](../src/frontend/website/modules/strava/views.cljs) · [Cursor regression](../test/cljs/website/strava_graph_test.cljs) · [Math functions](https://guide.clojure.style/#prefer-clojure-math-over-interop)
- Use a local named function when a callback closes over one value and only its caller uses it. Extract a private function when several callers share the work or it has its own contract, such as parsing a calendar cell or admitting a fetch to a bounded cache. A threading macro reads clearly when each form names one operation. A large anonymous reducer in the middle is a good place to try a named function. [Clojure style guide on threading](https://guide.clojure.style/#threading-macros)
- Prefer `clojure.string`, core collection operations and conditional destructuring when they express the domain operation directly. Keep a typed Java call where it expresses a real capability, such as parsing HTML, reading an input stream with a byte limit, or acquiring a semaphore. Keep resource ownership visible via `with-open` or an explicit release. [Clojure style guide](https://guide.clojure.style/) · [Resource management](https://guide.clojure.style/#prefer-with-open-over-finally)
