# Documentation maintenance

Keep these instructions and all repository `AGENTS.md` files up to date.

- Document current behavior, contracts, configuration and commands. Keep detailed
  user guides, expected schemas and working examples.
- Remove resolved investigation notes, obsolete branch/deployment status, duplicated
  explanations and historical pass counts. Git history retains development diaries.
- Link to the owning guide rather than copying it. Examples must follow the same
  re-frame/event/subscription and component conventions as production code.
- Distinguish live service checks from fixture/seed tests. Do not present old host
  capacity, endpoints or test results as current verified state.
